# My Neovim Config

### Install

Requires Neovim v0.12

Note: Neovim v0.11 version also [available](https://github.com/JeffC25/jeffc25.nvim/tree/0.11)

```sh
## or git clone git@github.com:JeffC25/jeffc25.nvim.git "${XDG_CONFIG_HOME:-$HOME/.config}"/nvim
git clone https://github.com/jeffc25/JeffC25.nvim.git "${XDG_CONFIG_HOME:-$HOME/.config}"/nvim
```

#### External Dependencies
- `tree-sitter` & `tree-sitter-cli` - for installing additional syntax highlighting parsers not built into Neovim
- `ripgrep` - for Telescope grep
- Additional LSPs - most can be installed via Mason
